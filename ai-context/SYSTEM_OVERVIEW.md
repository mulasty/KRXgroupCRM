# System Overview

The website is powered by multiple experience engines.

Hero Engine
Handles the initial 3D scene with particle reveal and mockups.

Design Universe Engine
Generates a procedural galaxy containing portfolio projects.

Portfolio Engine
Loads projects and assigns textures to mockups.

Case Study Engine
Displays detailed project presentations.

Global Interaction Engine
Central controller for scroll, cursor and scene interaction.

Animation Engine
GSAP based animation timelines.

Performance Manager
Ensures stable 60 FPS rendering.
